# Spring Boot Faculty Management REST API

A Spring Boot application demonstrating a simple Faculty Management REST API using Spring Data JPA and MySQL.

## Overview

This project implements CRUD operations for managing faculty records through RESTful APIs. It demonstrates how Spring Boot, Spring Data JPA, and a relational database can be integrated to build a backend application.

## Features

- Create a faculty record
- Retrieve all faculty records
- Update faculty details
- Delete a faculty record
- RESTful API endpoints
- JPA entity mapping
- Spring Data JPA repository
- Service-layer architecture

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API
